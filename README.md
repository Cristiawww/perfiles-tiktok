# perfiles TK


## Objetivo

Obtener determinados datos visibles de un perfil público y presentarlos de forma ordenada para facilitar su revisión.

## Tecnologías previstas

- **Python:** lenguaje principal del proyecto.
- **Playwright:** herramienta para automatizar la navegación y consultar el contenido de las páginas.
- **Streamlit:** biblioteca para crear una interfaz sencilla desde la cual realizar las consultas.

## Información que se busca obtener

- Nombre del perfil y nombre de usuario.
- Número de seguidores.
- Número de cuentas seguidas.
- Información de videos recientes.
- Cantidad de visualizaciones de los videos, cuando esté disponible.

## Estado del proyecto

El proyecto se encuentra en su etapa inicial. Primero se preparará el entorno de trabajo y después se desarrollará la extracción de datos, la interfaz y la exportación de resultados.

## Consideraciones

La herramienta estará orientada a información de perfiles públicos. Algunos datos pueden no estar disponibles debido a cambios en la página, restricciones de acceso o diferencias entre perfiles.

El proyecto no utilizará la API oficial de TikTok.
